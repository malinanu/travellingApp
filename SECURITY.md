| Version | Supported          |
| ------- | ------------------ |
| main    | :white_check_mark: |

## Reporting a Vulnerability
We take the security of Spotto seriously. If you discover a security vulnerability, please report it responsibly.
### How to Report
- **Email**: Please report security vulnerabilities to [mjjayaweera@gmail.com](mailto:mjjayaweera@gmail.com).
- **GitHub Advisory**: If Private Vulnerability Reporting is enabled, you can also report vulnerabilities confidentially via the **Security** tab &rarr; **Report a vulnerability**.
### What to Include
To help us triage and resolve the issue quickly, please include:
1. A summary of the vulnerability and its potential impact.
2. Step-by-step reproduction steps or a minimal proof-of-concept (PoC).
3. Any affected components (e.g., mobile app, backend API server).
### Response Process
- We will acknowledge receipt of reports within 48 hours.
- We will coordinate a timeline for remediation and public disclosure.
- Please do not disclose vulnerabilities publicly until a fix has been released.
